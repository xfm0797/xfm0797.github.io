「读完这篇，下一篇读什么」是内容站留住读者的关键一环。`xfm-plugin-related` 在渲染前为每篇文章算出相关推荐，写进 `page.data.related`，主题里有这个键就自动渲染推荐区块——不需要写一行模板代码。

## 它解决什么

相关文章本质是全站两两比较，放在单页钩子里算会把渲染拖回单线程。这个插件用 `afterCollect` 钩子：全部页面就位后一次性算完，worker 池不受影响，增量构建也不会留下过期的推荐（推荐列表参与页面缓存哈希）。

## 加权规则

相关性按三处重合打分：

| 重合点 | 分值 |
| --- | --- |
| 标签 | 每个共有的标签 3 分 |
| 分类 | 2 分 |
| 系列 | 3 分 |

得分达到 `minScore` 的文章按分数排序，同分按日期新到旧，取前 `limit` 篇。只推荐文章——首页、聚合页和普通页面不参与。从 0.4.17 起，多语言站点只在同语言文章之间推荐，中文文章不会推荐出它的英文版本。另外单个标签下最多考察最近 200 篇，避免「随笔」这类大标签淹没结果。

## 安装与配置

```bash
npm i -D xfm-plugin-related
```

```js
// xfm.config.mjs
export default {
  plugins: ['related'],
  related: {
    limit: 3,      // 每篇最多推荐几篇，默认 3
    minScore: 2,   // 最低得分门槛，默认 2
  },
};
```

装完即生效（`xfm dev` 运行中需重启）。本站也装了它，两套内置主题都会在有推荐数据时渲染推荐区块。

## 页面级控制

front-matter 可以逐篇干预：

```yaml
---
related: false              # 这篇不显示推荐
related:                    # 手动指定推荐列表（写站内地址）
  - /2026/11/21/xfmpress-quick-start/
  - /2026/11/21/xfmpress-config/
---
```

手动列表会覆盖自动计算的结果，仍然受 `limit` 截断。

## 注意事项

- 推荐质量取决于元数据质量：标签、分类、系列填得越准，推荐越对味。系列（`series`）权重最高，写连载教程时尤其值得用，系列概念见[内容组织](/2026/11/21/xfmpress-content/)
- `minScore: 2` 意味着只共用一个分类（2 分）也会上榜；想更严格可调到 3
- 插件只负责算数据，推荐区块的样式由主题决定，想改样式看[默认主题](/2026/11/21/xfmpress-theme-default/)
