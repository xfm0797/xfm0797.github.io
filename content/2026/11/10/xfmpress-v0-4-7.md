xfmpress 的功能早就超出了 README 能装下的范围：模板、主题、插件、部署……这些内容此前散落在 README 的各个小节里，想系统学习只能从头读到尾。v0.4.7 解决的就是这个问题——这一版不碰构建内核，专注把「文档」本身补齐。

## 这一版在解决什么

一个静态站点生成器的核心是构建速度和渲染正确性，但对新用户来说，第一道门槛往往是「我该从哪里开始」。v0.4.7 把安装、CLI、配置、内容、模板、主题、插件、部署、架构等主题整合成了一部结构化的官方手册，让「查文档」取代「读 README」。

## 变了什么

### Added

- **官方手册正式上线**，地址是 [doc.lovou.pw/docs/xfmpress](https://doc.lovou.pw/docs/xfmpress/)，共十个章节，覆盖安装、CLI、配置、内容、模板、主题、插件、部署与架构。
- 两份 README 都加入了 `docs` 徽章和 Documentation 表格；CLI、配置、插件、主题、部署等章节现在会直接链接到手册中对应的章节，而不是各自复述一遍。
- npm 包的 `homepage` 字段指向手册，脚手架生成的站点 README 也会引导读者去手册。
- 脚手架的 README 补全了全部十五个官方插件的列表——此前只列到九个，剩下的七个要自己去 `node_modules` 里翻。

### Fixed

- README 里声称的测试数量过期了（实际是 118，README 还写着 111），已修正。

## 升级要不要动手

不需要。这一版没有改动任何 API、配置项或构建行为，`npm update xfmpress` 之后即可继续用。如果你此前因为文档不全而把某些用法记在了自己的笔记里，现在可以去手册里找对应章节，把笔记换成链接了。
