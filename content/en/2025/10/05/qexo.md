# Getting Started

**Qexo** is a fast, powerful, and beautiful online **static blog editor**. Licensed under the GPL3.0 **open source** license. It can be deployed on platforms including but not limited to **Vercel**, adding **dynamic** elements to your static blog.
![](https://s2.loli.net/2024/07/19/r1XJPHnYANKbcRl.png)

## Featured Features

- **Post Management ~ Brand-New Interface**

  Version 3.0 of Qexo redesigned the post editing page, letting you edit posts more elegantly

  Supports uploading to multiple image hosts — uploading at your fingertips
  ![](https://s2.loli.net/2024/07/19/q3LlJutFDCvpbMh.png)
- **Caching ~ Speed First**

  Supports one-click caching of posts, pages, and configuration indexes to the database, ensuring fast access

  Webhook automatically clears the cache, keeping data fresh at all times
- **Small Package ~ Complete Features**

  - Modular architecture
  - Supports multiple Hexo, Hugo, and Valaxy hosts: Github, Gitlab, Local
  - Multiple image host protocols: Github, S3, FTP, remote API
  - Markdown syntax + multiple editing interfaces, WYSIWYG
  - Brand-new interface with one-click dark/light mode switching
  - Multiple notification channels: Bark, Telegram, Pushdeer, Wechat...
  - reCaptcha to prevent spam abuse
  - Friend links: frontend application, one-click integration
  - Auto updates: simple and convenient, always up to date
  - Custom fields / site analytics / page management / config editing
  - Comment notifications / image uploads / favicon generation / API extensions
