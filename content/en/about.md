This is the official website of **XFMpress** — a zero-dependency static site generator for Node.js.

## What you'll find here

- **xfmpress tutorials**: 11 articles broken down by topic, covering installation, configuration, theming, plugins, and deployment. Read them in order via the series page or the Chinese tutorials section
- **Archive posts**: records of building with Hexo, theme setup, Qexo deployment and more — this site started as a Hexo blog, and that experience eventually became xfmpress

## About the author

XFM, who enjoys tinkering with static sites and toolchains. Besides xfmpress, there is also the companion [hexo-theme-xfm](https://github.com/xfm0797/hexo-theme-xfm) theme.

## About this site itself

Built with xfmpress, automatically deployed to GitHub Pages via GitHub Actions, and served redundantly through Cloudflare Pages. Post permalinks keep the `/YYYY/MM/DD/<slug>/` format — unchanged since the Hexo days.

> Most posts on this site are written in Chinese. English content grows over time; start with [Getting Started](/en/2026/11/21/xfmpress-install/).
