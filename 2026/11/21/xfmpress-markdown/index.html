Markdown 扩展语法：容器、脚注与代码高亮

3 分钟阅读 # xfmpress# 教程

内置 Markdown 能力

正文就是标准 Markdown，GFM 常用语法全支持：表格、任务列表、删除线、自动链接。在此之上，引擎自带一批扩展，全部构建期处理，不引入任何运行时 JS。

提示容器

::: tip 提示标题
带标题的高亮提示框。
:::

支持 tip / info / warning / danger / details 五种类型，类型决定配色与图标；标题可省略；details 会折叠，适合放长附录。

代码块

围栏带语言标记就有语法高亮，还可在围栏首行附加标题：

```js app.js
const ok = true;
```

语言别名做了归一，大小写不敏感，覆盖 js / ts / java / c / cpp / go / rust / python / bash / json / yaml / html / css / vue / md 等常见语言；未知语言降级为纯转义文本，不会报错。围栏首行的元信息（如 {1,3-5} 高亮范围）会被忽略。

不想写围栏时，行首四个空格或一个 Tab 也能成缩进代码块，列表项内外都支持。

引用式链接

地址只需在文末写一次：

这几天在折腾[静态站点][ssg]，顺手把[文档][docs]也重排了一遍。

[ssg]: https://example.com/ssg "静态站点生成器"
[docs]: https://example.com/docs

定义行不会出现在正文里。简写形式 [ssg] 也支持——链接文字就是标识符时省掉第二对方括号。定义只在段落起始处生效，这是 CommonMark 的规定。

脚注

正文里插一句[^note]，文末自然出现注释。

[^note]: 按首次引用顺序编号，多处引用各自回链。

按首次引用顺序编号，每处引用都有独立回链。注释里放块级内容（第二段、子列表、代码块）需要缩进四个空格。

其他扩展

  • Setext 标题：段落下一行写 ====（一级）或 ----（二级）
  • 松散列表：项与项之间有空行仍是一个列表，段落补 <p>；有序列表保留起始编号（3. 起输出 start="3"）
  • 转义：\*不是斜体\*、\`不是代码\`
  • 任务列表：- [x] 已完成，支持缩进续行与嵌套

标题锚点与目录

二三级标题自动生成 id，中文标题也能得到可读锚点（重复标题自动加序号）。标题同时收集进 page.toc，主题据此渲染右侧目录并随滚动高亮当前小节——本站文章页右侧的目录就是这么来的。

toc: false 只影响目录，不影响锚点本身。

相对链接自动解析

Markdown 里写相对路径，构建时按源文件位置解析成正确的站点 URL：

参见 [上一篇](./xfmpress-content.md)。

指向不存在源文件的 .md 链接保留原样——拼错不会静默变成怪路径。
