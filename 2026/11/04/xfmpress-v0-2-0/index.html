xfmpress v0.2.0：Markdown 渲染能力大幅补齐

3 分钟阅读 # xfmpress# 更新日志

0.2.0 是一次面向写作体验的版本：把日常写作中常见、但此前不支持的 Markdown 语法一次补齐，同时修掉了两个会让文章"写不出来"或"渲染出错"的解析问题。如果你在迁移旧博客，这一版之后兼容性会好很多。

这一版在解决什么

0.1.x 的渲染器只覆盖了基础语法，遇到学术写作或迁移过来的旧文章就露怯：脚注写不了、[text][id] 引用式链接不解析、段落下方用 ==== 划线的 Setext 标题不认。更糟的是两个边缘 bug——标题里含 : 或 # 时 front-matter 会变成无法解析的 YAML，整篇文章直接失败。这一版把这些一次性补上。

变了什么

Added

  • 引用式链接和图片：[text][id]、简写 [id]、![alt][id]，从统一的 [id]: url "title" 定义解析，定义本身不再泄漏进正文。
  • 脚注：text[^1] 配 [^1]: note，按首次引用顺序编号，每个引用处带回链，文末生成 .footnotes 区块。
  • Setext 标题：段落下一行 ==== 为 h1、---- 为 h2。
  • 四空格 / Tab 缩进代码块、反斜杠转义（\*literal\*）、CommonMark 风格的列表懒续行。
  • 有序列表保留起始编号，3. 渲染为 <ol start="3">。
  • xfm new 遇到同名标题时自动编号为 title.md、title-2.md，不再报错退出。

Changed

  • 标题锚点和 TOC 条目忽略行内标记，## Use [xfm](/x) **now** 的锚点变成 use-xfm-now 而不是 use-xfmx-now。
  • 自动摘要去掉链接定义、脚注定义和脚注标记，不再把 [id]: https://… 当正文输出。
  • front-matter 双引号字符串按 JSON 语义解转义（\"、\n），单引号内的 '' 也正确处理；新文章的标题写成双引号形式，含中文冒号等字符也不破坏 YAML。

Fixed

  • 标题含 YAML 特殊字符（: / #）时 front-matter 无法解析的问题。
  • 引用块、提示框和表格内的引用式链接此前不解析（嵌套渲染时定义域是空的），现在正常工作。

升级要不要动手

直接升级即可，没有破坏性变更，也不需要改配置。已有的文章只会渲染得更正确——尤其是之前锚点被行内标记污染、摘要里出现链接定义的地方。写作语法细节可参考 Markdown 支持教程。
